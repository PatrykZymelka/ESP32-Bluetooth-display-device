Wireless bluetooth device set up with 7 segment display (8 digits) and 2 0,91 Oled screens, which both can be setup and altered using a desktop python application controlled fully via bluetooth.

Main components:
- ESP32 WROOM CH340
- OLED 0,91 SSD1306
- 7 Segment display Max7219 (8 digits)

Stages of the project:
1) Initial project research
2) Setup simple python desktop app:
   - Connection to BLE
   - Simple UI in customtkinter
3) Setup BLE on ESP32
4) Setup of OLED displays
5) Setup of 7 Segment display
6) Sending data from desktop to board
